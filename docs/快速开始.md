# 数据开发工程师技能套件 - 快速开始

## 🚀 快速入门（约 10 分钟）

### 📋 前置条件

在开始之前，请确认：
- ✅ 已安装 [Claude Code CLI](https://claude.ai/docs/cli)（运行 `claude --version` 验证）
- ✅ 有 Bash 环境（macOS/Linux 自带，Windows 用户推荐 Git Bash 或 WSL）
- ✅ 网络可访问 Claude API

### 第一步：安装技能套件

```bash
# 全局安装（推荐）：将技能套件复制到 Claude Code 的 skills 目录
cp -r <你的项目路径>/data-engineer-skills ~/.claude/skills/

# 项目级安装（仅在特定项目中使用）
cp -r <你的项目路径>/data-engineer-skills /your/project/.claude/skills/
```

> 💡 将 `<你的项目路径>` 替换为实际路径，如 `./` 或 `/Users/yourname/workspace`。

### 第二步：启动Claude Code

```bash
claude
```

### 第三步：运行第一个示例

```bash
# 端到端示例（推荐新手）
/skill-hub 端到端建设简单的订单数仓：
- 数据源：订单表（order_id, user_id, amount, order_time）
- 目标：统计每日订单量和销售额
- 数据库：MaxCompute
```

## 📋 常用命令速查表


```bash

/modeling-assistant 设计{业务}维度模型

# 示例
```

### SQL开发

```bash
# 生成SQL
/sql-gen 使用{数据库}语法，{查询描述}

# 示例
/sql-gen 使用MaxCompute语法，查询过去7天每日订单量

# 审查SQL
/sql-review {SQL代码或文件路径}

# 分析执行计划
/sql-explain {EXPLAIN输出}
```

### 数据质量

```bash
# 生成质量规则
/dq-rule-gen 为{表名}生成质量规则

# 示例
/dq-rule-gen 为订单表生成质量规则

# 生成数据字典
/dq-doc {表名}
```

### 数据测试

```bash
# 生成测试
/test-engineer 基于{上游包}生成测试

# 示例
/test-engineer 基于 dq_package.yaml 生成测试用例
```

### 联动工作流


## 🎯 30分钟实战练习

### 练习1：创建订单分析表

```bash
# 步骤1：建模（5分钟）
/modeling-assistant 设计订单事实表：
- 粒度：订单级别
- 字段：order_id, user_id, order_time, amount
- 使用MaxCompute

# 步骤2：生成DDL（5分钟）
/sql-assistant 基于以上模型生成MaxCompute建表DDL
# 包含分区定义

# 步骤3：生成查询（5分钟）
/sql-gen 使用MaxCompute语法，查询2024年1月每日订单量

# 步骤4：建立质量规则（5分钟）
/dq-assistant 为订单表建立质量规则：
- order_id非空
- amount为正数

# 步骤5：生成测试（5分钟）
/test-engineer 基于质量规则生成单元测试
```

### 练习2：使用ADB MySQL

```bash
# ADB MySQL建表
/sql-gen 使用AnalyticDB MySQL，创建按月分区的订单表：
- 分布键：order_id
- 分区：按月

# ADB MySQL查询（带分区裁剪）
/sql-gen 使用ADB查询202401月销售数据，包含分区裁剪优化
```

## 💡 使用技巧

### 技巧1：明确指定数据库

```bash
# ✅ 推荐：明确指定
/sql-gen 使用MaxCompute语法，查询每日销售额

# ❌ 不推荐：不指定数据库
/sql-gen 查询每日销售额  # 可能生成错误方言
```

### 技巧2：提供表结构信息

```bash
# ✅ 推荐：提供DDL或字段信息
/sql-gen 查询订单表（字段：order_id, user_id, amount, order_time）
       过去7天的订单量

# ❌ 不推荐：不提供表结构
/sql-gen 查询过去7天订单量  # 无法确定字段名
```

### 技巧3：使用标准包文件

```bash
# 利用上游输出
/sql-assistant 基于 modeling_package.yaml 生成DDL
/dq-assistant 基于 modeling_package.yaml 生成质量规则
/test-engineer 基于 dq_package.yaml 生成测试
```

### 技巧4：分步执行复杂任务

```bash
# 复杂建模，分步执行
/modeling-assistant 第一步：设计订单事实表结构
/modeling-assistant 第二步：设计用户维度表
/modeling-assistant 第三步：整合为完整模型包
```

## 🆘 新手常见问题

### Q: Skill命令不触发？

检查安装路径：
```bash
ls ~/.claude/skills/data-engineer-skills/SKILL.md
```

### Q: 生成的SQL有问题？

确保明确指定：
1. 数据库类型
2. 表结构信息
3. 查询目的

### Q: 不知道用什么模块？

按以下顺序：
1. 新项目 → `/skill-hub 端到端开发`
2. 只需要SQL → `/sql-assistant`
3. 需要建模 → `/modeling-assistant`
4. 需要质量 → `/dq-assistant`
5. 需要测试 → `/test-engineer`
