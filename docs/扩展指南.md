### MaxCompute 方言扩展

#### 特有语法

```sql
-- 1. MAPJOIN 提示（小表JOIN优化）
SELECT /*+ MAPJOIN(dim_user) */
    o.order_id,
    u.username
FROM orders o
JOIN dim_user u ON o.user_id = u.user_id;

-- 2. 分区表查询
SELECT * FROM orders
WHERE pt = '202401'   -- 一级分区
  AND dt = '01';      -- 二级分区

-- 3. 动态分区
INSERT OVERWRITE TABLE orders PARTITION(pt, dt)
SELECT 
    order_id,
    user_id,
    DATE_FORMAT(order_time, '%Y%m') AS pt,
    DATE_FORMAT(order_time, '%d') AS dt
FROM source_orders;

-- 4. UDF 调用
SELECT 
    my_udf(column1, column2) AS result
FROM my_table;

-- 5. 窗口函数
SELECT
    order_id,
    user_id,
    ROW_NUMBER() OVER (PARTITION BY user_id ORDER BY order_time DESC) AS rn
FROM orders;

-- 6. PyODPS 特有
-- 使用Python脚本处理数据
```

#### 数据类型

| 类型 | 说明 | 示例 |
|------|------|------|
| `BIGINT` | 64位整数 | `1234567890` |
| `DOUBLE` | 双精度浮点 | `3.14159` |
| `STRING` | 字符串 | `'hello'` |
| `DATETIME` | 日期时间 | `2024-01-15 10:00:00` |
| `BOOLEAN` | 布尔值 | `TRUE/FALSE` |
| `DECIMAL` | 高精度小数 | `DECIMAL(18,2)` |
| `ARRAY` | 数组 | `ARRAY<STRING>` |
| `MAP` | 映射 | `MAP<STRING,STRING>` |

#### 函数对照

| 功能 | ADB MySQL | MaxCompute |
|------|-------|------------|
| 当前日期 | `CURDATE()` | `GETDATE()` |
| 日期格式化 | `DATE_FORMAT(d,f)` | `DATE_FORMAT(d,f)` |
| 字符串拼接 | `CONCAT(s1,s2)` | `CONCAT(s1,s2)` |
| 条件判断 | `IF(cond,a,b)` | `CASE WHEN cond THEN a ELSE b END` |
| 分组连接 | `GROUP_CONCAT()` | `WM_CONCAT()` |

#### DDL示例

```sql
-- MaxCompute 分区表创建
CREATE TABLE IF NOT EXISTS orders (
    order_id BIGINT COMMENT '订单ID',
    user_id BIGINT COMMENT '用户ID',
    order_time DATETIME COMMENT '订单时间',
    amount DECIMAL(18,2) COMMENT '金额',
    status STRING COMMENT '状态'
)
COMMENT '订单表'
PARTITIONED BY (
    pt STRING COMMENT '月分区',
    dt STRING COMMENT '日分区'
)
LIFECYCLE 365;  -- 数据生命周期365天

-- 添加分区
ALTER TABLE orders ADD PARTITION (pt='202401', dt='01');

-- 删除分区
ALTER TABLE orders DROP PARTITION (pt='202312', dt='01');
```

#### 性能优化

```sql
-- 1. 分区裁剪（必须）
SELECT * FROM orders
WHERE pt = '202401' AND dt >= '01' AND dt <= '31';  -- 分区裁剪

-- 2. MAPJOIN（小表JOIN）
SELECT /*+ MAPJOIN(small_table) */ *
FROM large_table l
JOIN small_table s ON l.key = s.key;

-- 3. 小文件合并
SET odps.sql.reducer.instances=100;

-- 4. 并行执行
SET odps.sql.parallel.factor=10;
```

### MaxCompute 特有规则

| 规则类型 | 说明 | SQL模板 |
|---------|------|---------|
| `partition_check` | 分区完整性 | `SELECT COUNT(*) FROM table WHERE pt = '{partition}'` |

### 业务规则示例

```yaml
# 电商业务规则
rules:
  - name: "order_amount_limit"
    type: "custom"
    description: "订单金额上限检查"
    sql: "SELECT COUNT(*) FROM orders WHERE amount > 1000000"
    threshold: 0
    severity: "warning"
    
  - name: "user_order_ratio"
    type: "custom"
    description: "用户订单比例检查"
    sql: |
      SELECT COUNT(DISTINCT user_id) * 1.0 / COUNT(*)
      FROM orders
    threshold: 0.5
    severity: "error"
```

## 工作流定制

### 自定义工作流

```yaml
workflows:

  maxcompute_offline_pipeline:
    name: MaxCompute离线开发
    description: 需求分析 → 建模 → MaxCompute SQL → 质量 → 测试
```

## 企业级扩展

### 团队规范定制

创建 `company-standards.yaml`：

```yaml
company:
  name: "数据团队"

naming:
  tables:
    pattern: "{业务域}_{表描述}"
    example: "sales_order_facts"

  columns:
    pattern: "snake_case"
    example: "order_id, user_id"

security:
  pii_fields:
    encryption: "AES-256"
  audit:
    retention: "3-years"

quality:
  mandatory_rules:
    - "primary_key_not_null"
    - "pii_encrypted"

cost:
  compute_budget: "$5000/month"
  alert_threshold: 80%
```

### 初始化脚本定制

修改各模块的 `scripts/init-project.sh`：

```bash
# 添加团队标准
cp company-standards.yaml $PROJECT_DIR/standards.yaml

# 创建团队标准目录结构
mkdir -p $PROJECT_DIR/{docs,scripts,configs}

# 添加企业特定配置
cat > $PROJECT_DIR/configs/db_config.yaml << 'EOF'
maxcompute:
  project: "${MAXCOMPUTE_PROJECT}"
  endpoint: "${MAXCOMPUTE_ENDPOINT}"

adb_mysql:
  host: "${ADB_HOST}"
  port: 3306
  database: "${ADB_DATABASE}"
EOF
```
